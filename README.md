# Operational Approach Mapper — Codespaces Ready (Preloaded)

A complete, classroom‑ready JP 5‑0 operational approach builder and live one‑slide visual.

## Run in Codespaces
```bash
npm install
npm run dev
```
Open the forwarded port. The app **preloads example data** on first run. You can still Export/Import JSON.

## Build to /docs for GitHub Pages
```bash
npm run build
```
Then enable Pages → Source: `/docs` in your repo settings.

## Tests
```bash
npm run test
```
